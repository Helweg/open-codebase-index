## Global gates and remaining limitations

- Final TypeScript/native build, built-CLI smoke, typecheck and lint passed. The combined command reached the background runner's 600-second limit during Vitest, so the complete suite was rerun separately: **119 files and 1,861 tests passed** in 385.13 seconds. All 344 frozen implementation/test/build file hashes remained unchanged.
- Rust formatting and strict Clippy passed. Debug-profile native tests passed 141/142, with the unchanged 10,000-node community timing test failing its one-second median budget. The baseline comparison had used release mode, so it did not isolate the debug failure. A matching current **`cargo test --release --lib -- --test-threads=1` passed all 142 tests** in 3.89 seconds, including the original performance budget. No thresholds were changed; the debug-profile timing failure remains disclosed.
- Clean-package smoke verification passed in 73.5 seconds.
- Exact-root, same-index back-to-back evaluation retained Hit@5 75% / 100% and MRR 0.6354 / 0.8333. All 17 representative ordered locations, candidate counts and token metadata matched baseline, with two score-only differences in one query. All three pre-edit outputs matched except latency. The earlier fallback candidate difference disappeared when absolute paths were identical. Representative p95 was 318.174 ms integrated versus 289.284 ms baseline. An earlier same-root run during compilation measured 7,573.708 ms, demonstrating load sensitivity, not a speed improvement. Both executables reused the current native binary, so this isolates TypeScript behavior, not native implementation differences. No competitor-superiority claim is made.
- Independent review subsequently found that long-lived structural readers did not refresh another writer's BM25 publication. The correction adds same-reader add/delete visibility, invalid-publication blocking/recovery, and worktree isolation tests. The post-fix gate passed **119 files / 1,864 tests**, TypeScript build, typecheck, lint, and clean-package smoke on 2026-09-10. That review then reproduced a WAL-only stale-read case, corrected as recorded below.
- The local runtime is Node 26.6.0 on macOS ARM64. This is not a five-platform release matrix or a Node 22/24 CI result. SCIP remains an experimental disabled-by-default pilot; its broader two-repository precision/performance expansion gate has not been met.
